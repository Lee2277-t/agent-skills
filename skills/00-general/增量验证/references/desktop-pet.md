### 三个容易选错的例子

- **只改动作节奏**：追踪动作定义到 renderer 的执行、收尾及对应打断；选相关动作检查。不跑题库全流程、真实模型、唱歌音质；若改的是全局忙碌优先级，再检查其实际消费者。
- **只改聊天按钮文案**：例如 `chat.html` 中 `#send` 的显示文字，先确认不是分支判断用的字符串，再检查该窗口文字、布局与按钮行为。`data-text` 是快捷话题实际发送的内容，改变它还需检查发送值，不能当纯显示文案。不自动跑语音、动作和所有聊天协议测试。
- **改共享音量**：实际链为聊天设置 → `voice:save` → voice 配置保存/广播 → renderer 的普通语音和歌曲音频，以及聊天窗口试听。用合成音频检查零音量/中间值/满音量、当前播放和后续播放、保存后隔离重载；按改动检查静音与唱歌互斥。不调用真实 TTS 或跑歌声渲染来证明音量设置。

## 历史脚本不能直接当长期验收入口

`参考图/retire-computer-v1/verify.js` 会把运行文件与当时 `deployed.json` 的 SHA256 逐个比较，还会读取旧 `ui-report.json` 和 `regression-report.json`。正常新改动也会使它失败；旧报告不证明当前行为通过。

项目 AGENTS.md 将该脚本列为退役能力门禁，不能静默跳过要求。后续变更时分清：

1. 旧交付哈希/归档一致性检查，适用于对应旧快照。
2. 当前仍有效的退役能力要求：相关入口、IPC、模块加载和后台服务不得重新接入。

保留第二类要求的当前版本证据；第一类不匹配应报告为快照失效，不修改新业务来凑旧哈希，也不偷偷改 `deployed.json` 或复用旧报告制造通过。若指令明确要求该原脚本本身通过且尚未更新验证约定，如实报告该项未通过及原因，不能声称全部强制检查通过。

删除入口应从实际运行链检查：菜单/按钮 → preload → IPC → 模块初始化 → 后台任务和关闭清理；同时确认共用保留能力。例如退役电脑能力影响了共享主进程、菜单和渲染器时，才按交接点验证聊天、触摸或唱歌门禁；不是把已退役脚本重跑一遍。

## 执行环境与隔离

- 纯 Node：`.dev/node/node.exe`；Electron：`node_modules/electron/dist/electron.exe`。先确认文件存在。不安装全局 Node，不用其他应用自带的 Electron 替代项目版本。
- Electron 子进程环境删除 `ELECTRON_RUN_AS_NODE`；不要改变用户全局环境。记录项目工作目录、脚本参数、退出码及成功标记；脚本通过但没有覆盖目标行为仍需补证据。
- PowerShell 对每个修改的 JS 文件分别执行 `& $nodeExe --check $changedFile`。`node --check a.js b.js` 不能作为两个文件均已检查的证据。不要启动 `npm start` 来代替隔离验证。
- 运行前核对脚本是否在加载应用前重定向 userData。使用本次唯一测试目录；固定目录脚本若可能冲突，做必要的隔离适配。模拟 HTTP 服务绑定回环地址，端口用 0，不探测实际服务。
- 不读写真实 `%APPDATA%\desktop-pet`，不读私人参考音频，不重启/关闭用户桌宠，不探测真实 9880，不调用付费接口或擅自下载模型。
- 音量、互斥及协议验证用合成音频/模拟服务。模拟结果只证明对应逻辑，不等同于真实接口或音色通过。
- `.dev/qa-real-pack.js` 会读取真实配置；`sing-e2e.js` 使用真实引擎和网络；`qa-real-download.js` 真下载；`qa-rvc-status.js`、`qa-rvc-card.js` 会临时写真实权重目录标记。这些不属于默认增量验证，不可因名字含 qa 就直接运行。
- 需要显示的测试窗口按脚本设置使用 `showInactive()`；隐藏/遮挡可能导致动画不推进或截图失败，先查测试环境，不能放宽业务断言。
- 清理和超时仅处理本次创建的目录和进程，按精确 PID/启动命令核对，不能结束全部 electron.exe/python.exe。长耗时脚本运行期间继续提供简短进度。

系统级透明穿透、真实拖拽手感、多显示器和声音听感仅在此次受影响时列为人工待验。脚本截图或合成输入不能替代这些证据；不要要求用户每次重测整套功能。

## 技能范围选择演练

维护技能时使用当前源码与测试入口核对这些情景；这是选择演练，不是桌宠功能已实测的证明。不必改业务或重跑整套回归。

| 输入情景 | 应得到的范围与证据 |
|---|---|
| 修改一个动作的节奏 | 目标动作收尾/打断及必要共享状态；排除题库和真实声音 |
| 替换小形态专用帧 | 目标图片加载/透明/对齐，必要的动作与命中检查；不能只查 JS 差异 |
| 修改聊天按钮文案 | 确认未参与逻辑分支，检查目标窗口布局和按钮；排除无关协议与音频链 |
| 修改共享音量 | 追到普通语音、唱歌、试听与配置重载；不能只测滑块或只跑唱歌门禁 |
| 删除功能入口 | 检查残留调用、注册/任务与共享保留功能；不恢复退役功能来满足旧脚本 |
| 无 Git、改完后无基线 | 明确无法证明完整删除范围，按当前入口补可得证据；不伪造修改前快照 |
| 正常修改后旧哈希脚本失败 | 分离历史快照与当前行为，报告原门禁未通过的具体原因，提供当前退役要求证据；不篡改旧清单 |
