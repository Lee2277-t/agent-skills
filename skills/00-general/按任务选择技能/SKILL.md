# 按任务选择技能

优先使用当前会话提供的技能目录，按名称与描述选出相关项，仅在准备使用时读取正文。正文长度与实际调用成本有关，但固定字符/token 比、原作者 DSH 实测额度和“最多三个”不能当成通用结论。

## 选择

1. 判断用户目标、输入输出和宿主可用能力。用户点名的技能先纳入；职责明显时直接读取，不为选择而扫描整库。
2. 只有候选较多或要排查误触发时用本地扫描辅助。以下命令相对技能目录：

   ```text
   python scripts/scan.py --root <某用途分类目录> --task "本次需求" --json
   ```

   `--root` 可重复，扫描该根目录直接子项。默认仍是原 DSH/agents 安装路径；Codex 或本资料库要显式传实际根目录。它会在本地读取 SKILL.md 来解析头部，不等于把所有正文都注入模型。
3. 检查排名的实际含义：关键词分数只提名候选，不能判断全部语义或授权；同名技能按根目录先后去重。排除环境不可用、仅词语重合或触发范围不符的项，不盲选前三。
4. 选择完成任务所需的最少组合，不设置固定数量上限。说明各技能负责什么，随后执行任务，不把选择清单当成任务完成。

## 可选 DSH 管理工具

`ledger.py` 和 `park.py` 是原 DSH 管理工具，分别写 `~/.dsh/skill-ledger.jsonl`、移动 `.dsh/skills` 或 `.agents/skills` 的目录。它们不是本库/Codex 的通用维护入口；本技能默认不运行账本写入或任何停用/恢复动作。

只有用户明确要求管理相应 DSH 目录，且路径、影响清单和权限均核对后才另行使用。移动前必须确认源和目标的绝对路径位于预期目录，不能接收任意路径作为技能名。账本无记录代表未知，不代表未使用或应停用。不要仅凭记录或分数自动关闭技能。

按需参考 [任务映射](references/routing-table.md) 与 [DSH 维护资料](references/maintenance.md)；其中历史工具名不保证当前可用。当前范围及原包权利说明见 [_来源.md](_来源.md)。
