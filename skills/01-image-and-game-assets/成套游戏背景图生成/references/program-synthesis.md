## 10. ⚠️ ImageGen 整幅重绘 → 「只改一块地」这类需求改走【纯程序合成】（2026-10-04 农业区实测）

### 10.1 决定性证据：ImageGen 每次都会整幅重绘

之前一直用「某块区域色差明显大于别处 → 改动只在那」判定"只改了局部"。**这个判据是错的**。
同法复核 v1 vs 原版：

| 区域 | v1 色差 | 两块耕地版 色差 |
|---|---|---|
| 中央农田（**目标区**） | 34.8 | 34.4 |
| 葡萄园（**不该动**） | **35.4** | 33.7 |
| 酒庄（**不该动**） | **36.3** | 39.8 |
| 松树林（**不该动**） | 12.8 | 14.1 |
| 天空（**不该动**） | — | 17.5 |

**不该动的地方改动量和目标区一样大** → 从 v1 起就是整幅重绘。只有"构图位移=0"是真的。
**结论：凡"只改某一块、其余全不动"的需求，别用 ImageGen，用程序合成。**

### 10.2 ✅ 纯程序合成：以原版为底图，只在遮罩内合成

```python
out = 原版图.copy()                      # 未改动像素 100% 原样（这是最大优势）
mask = 手写多边形（读图定位，见 §9.2c）   # 只圈目标区
soil = 合成泥土(...)                      # 见 10.3
out = 原版*(1-a) + soil*a                 # a = erode(mask) → GaussianBlur(窄)
```
实测把改动**完全收在目标区**：
两田区 8.70 / 葡萄园 **3.00** / 酒庄 **2.04** / 松树林 **1.19** / 天空 **0.32**
（对比 v1 的 35 / 36 / 13，是数量级改善）。

### 10.3 合成"翻耕泥土"的 6 个坑（都踩过）

1. **❌ 不能保留原图高频**（那是玉米叶/穗，直接乘进去会变成一排排"枯草纹"）。
   → 只保留原图**低频明暗骨架**：`lo_src = GaussianBlur(4)(原图).mean(axis=2)`。
2. **❌ 亮度不能贴近草地**。定在草地 ×0.97 → 变成"灰雾涂层"；定在 **×0.86** 才对
   （翻耕土本来就比草地深）。
3. 土色用 `SOIL=[188,148,100]`，`soil = SOIL*(0.50+0.66*ll)`，`ll=clip(lo/128, 0.45, 1.55)`。
4. 犁沟叠加强度 **34**（弱了看不出田垄；配合 §9.3 的 FFT 验收到能量比 ~1900）。
5. **❌ 羽化半径大了 → 耕地外围出现"喷枪晕圈"**。合成掩码用 `erode(3×3)` + `GaussianBlur(1.8)`；
   抹高频掩码用 `GaussianBlur(1.2)`。
6. **⚠️ 最关键**：`GaussianBlur` 抹高频时，**遮罩外的像素必须先替换成遮罩内的均值再模糊**，
   否则那圈"抹高频"会把**外面草地的颜色扩散进来**，边缘形成一圈绿雾：
   ```python
   fill_mean = O[core].mean(axis=0)
   inner = np.where(core[:,:,None], O, fill_mean[None,None,:])
   inner_soft = GaussianBlur(4)(inner)
   base = O*(1-a2) + inner_soft*a2
   ```

### 10.4 该用哪条路线？决策表

| 需求 | 路线 |
|---|---|
| 只改一块地/一个物件，其余**全不动** | **纯程序合成**（原版为底 + 多边形遮罩） |
| 整张重画、换季节/天气/时段 | ImageGen（image1 内容 + image2 明暗尺子） |
| 改一块地，但要求**风格也要变**（如改画风） | ImageGen，并接受整幅重绘 |

### 10.5 交付话术（诚实说明）

程序合成路线的交付必须说明：
- 未改动区域是**原版像素 1:1**（不是重绘），所以"其余不变"这条是**硬保证**；
- 目标区的泥土是**程序合成**的，不是 AI 画的，质感偏"规整"，若要更手绘感可再叠水彩纹理；
- 仍然**看不到最终画面**时要请用户过一眼（读了图之后这条已基本解决）。
