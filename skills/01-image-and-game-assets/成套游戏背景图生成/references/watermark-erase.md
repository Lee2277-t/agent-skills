## 6. 贴片去水印的两个新坑（2026-10-01 实测，工业区线）

场景：1536x1024 生成图归一成 960x600 后，右下角 "AI生成" 水印压在深灰地面上（亮、低饱和、中性色判据可定位，bbox 约 x885-949 y582-599）。

1. **底边羽化会把水印混回来**：水印一直延伸到图像底边（y=599 贴边）。若贴片区域四边都做"距边缘越近越保留原像素"的线性羽化，底边 1-2 行几乎完全不替换，验收时会留一排字形残影。**修正：羽化只做上/左边缘（`d = min(x-X0, y-Y0)`），底边和右边贴边直接替换。**
2. **取样策略分界线不是羽化边界**：主块（横向取样 DA=-100）与纸边条（纵向取样 KB=-46）的分界 x 只是取样策略切换点，若把它算进 `dx = min(x-X0, PAPER_X-x)`，分界附近的像素会被过度羽化、把水印半保留。dx 只看处理区域的左/上边缘。

配套脚本：`_work/patch_wm_fixed.py`（参数化贴片+复检打印残留 n）、`_work/make_overview.py`（总览拼图）。
验收标准：残留亮像素 n<=6 且放大右下角无字形（自然亮石板会贡献少量误报）。

## 7. 水印擦除：乡村线（草地背景）的完整打法（2026-10-01 实测）

场景与工业区（§6）不同：水印压在**草地/葡萄园**上，背景是**有笔触纹理的黄绿色**，
不是中性灰石板。这一节的三条教训都是踩出来的，直接照做。

### 7.0 先定位：水印的确切像素范围

乡村线（960×592）三张图水印位置**完全一致**：

| 内容 | 行范围 | 列范围 |
|---|---|---|
| 第一行 `AI生成` | y 551–576 | x 846–944 |
| 第二行 `WORKBUDDY` | y 580–591 | x 755–950 |

**定位方法（可靠）**：取一条同高度的干净带（水印正左侧 x620–770）作基线，
算「该列白度 − 基线白度」，逐列/逐行看超标范围。白度定义为
`0.5*亮度 + 0.5*蓝通道`——**半透明白叠加会把蓝通道抬得最明显**（草地原本 B 很低），
只用亮度会漏判。

### 7.1 ❌ 不要做「像素级抠图」（只盖住"比背景亮"的像素）

第一版按"亮于邻域 → mask → 修补"做，实测 **mask 覆盖率只有 65.4%**：
文字笔画之间有空隙，空隙不算"亮"，于是没被盖住；修补完仍留**文字形状的淡痕**。
且 mask 里混进大量草地噪点。

**✅ 正确做法：把水印当作「一个连续矩形块」整体替换。**
外框取 `x 700–960, y 546–592`（含抗锯齿余量与两行之间的空隙），整块修补。

### 7.2 ❌ 底边羽化会把水印混回来（与 §6.1 同一个坑，乡村线同样踩到）

水印第二行一直贴到画布底边（y=592）。若矩形四边都做"越靠边越保留原像素"的羽化，
底边几行几乎不替换 → 残留一排字形。
**✅ 修正：上边和左右羽化，下边（贴画布底）直接替换、不羽化。**
羽化宽度：上 16px、左右 12px 足够；再叠一次 `GaussianBlur(1.4)` 的接缝柔化。

### 7.3 ❌ 低频基底取「左右+上方均值」会**提亮**暗草地，反而凸显水印

雨夜右下角本身偏暗（雨雾+背光），把周边均值当低频基底填进去，等于给那块"打光"，
水印反而更显眼（实测这一版比原图还差）。
**✅ 正确做法：色块（低频）用目标区自身的低频，只把"纹理细节（高频）"从别处搬来。**
```python
fill = low(tgt, 12) + (src - low(src, 12))   # 低频保留原地形，高频用源纹理
```
`src`（纹理源）**优先取正左侧同高度的干净草地**（离水印最远，不受污染），
不要取正上方——正上方那一条往往也被水印的半透明边缘轻微波及。

### 7.4 夜图 / 雨雾图的特例

雨夜那块区域雾重、色差小、对比低，**同一天的雨晨脚本参数不适用**。
对这类图改用**"整块换源"**：从画面里另一处干净的同高度草地带（如 y452–500）
搬一块同尺寸纹理过来，低频桥接到目标区邻域中值上，再羽化贴入。实测残差可降到 +1.5。

### 7.5 验收口径（别只看数值）

**数值会骗人**：同一块草地的"右下 vs 正上方"天然就可能有 +8~+18 的白度差
（右下受光/雾影响），但这**不是水印**。判据是**「修补前后数值是否变化」**——
擦掉水印后该区白度必须下降；若"109.0 → 109.0"纹丝不动，说明你要擦的东西根本不在那儿。

**最终验收 = 放大右下角 ×3 目视**，确认无字形、无补丁框、纹理连续。
脚本：`_工具脚本/remove_watermark.py`（矩形整体修补 + 低频/高频分解 + 复检打印）。
