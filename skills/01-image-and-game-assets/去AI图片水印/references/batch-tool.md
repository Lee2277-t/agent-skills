# 批量 / 工具化去水印

把「检测 → 修补 → 计数 → 交人判不合格」固化成算法，逐张调坐标的手工流程不适合批量。以下内容按可直接照抄的阈值与判据写，实现见本机 `<project-root>\watermark-remover`（`remover/detection.py`、`remover/image_ops.py`、`remover/video_ops.py`）。

## 何时走这条路

一批同模型出图、嵌进生成流水线、多页文档扫描页、视频。手工贴片的坐标不可迁移（换题材/换画幅/换季节都要重量基线），批量必崩。

## 角落水印自动检测判定链

半透明白字（「AI生成」这类），逐条照抄：

1. **四角 ROI**：`w = max(60, 0.38W)`、`h = max(45, 0.24H)`，四角各扫一遍。
2. **局部中值差**（不要用绝对亮度阈值，那是误判的主源）：`k = clip(0.018·min(W,H), 11, 31)` 取奇数，`diff = gray − medianBlur(gray, k)`，命中 `diff ≥ 5`。
3. **HSV 门槛**：`V ≥ 125 且 S ≤ 72`。
4. **形态学**：`2×2` open 去噪点，`5×3` close 连笔画。
5. **连通域过滤**（这层决定误报率）：`w ≥ max(7, 0.004W)`、`h ≥ max(4, 0.006H)`、`w ≤ 0.34W`、`h ≤ 0.16H`、`area ≥ 8`、填充率 `area/(w·h) ≥ 0.06`。
6. **聚类**：把「AI生成 / WORKBUDD…」两行并成一框，`gap = max(8, 0.018·min(W,H))` 内合并。
7. **形状与位置闸门**：簇 `w ≥ max(12, 0.012W)`、`h ≥ max(7, 0.01H)`、`w ≤ 0.4W`、`h ≤ 0.2W`、**`w/h ≥ 1.05`**（横排文字）；必须落在近角 margin 内（`x: max(18, 0.13W)`、`y: max(14, 0.12H)`）；`pixel ≥ 24`、`density ≥ 0.035`；连通块数 `< 2` 时还要 `w ≥ 0.035W 且 density ≥ 0.14` 才放行。
8. **打分取最优**：`proximity = max(0, 1 − (gapX/(0.13W) + gapY/(0.12H))/2)`，`score = 0.012·pixel + 2.8·components + 18·proximity + 12·density`。最高分簇再吸收同角、`Δx ≤ 0.025W` 或 `Δy ≤ 0.035H` 内的其它簇。
9. **pad 与输出**：`padX = max(8, 0.009W)`、`padY = max(7, 0.011H)`，向外扩再裁到画面内；对外统一输出**归一化** `x/y/w/h`（5 位小数）。
10. **与手工坐标互相校验**：归一化左上角 ≈（手工流程里 bbox 左上角 − pad）/ 尺寸。960×592 案例 bbox 左上 `889,549` → `881,542` → `0.918, 0.916`；1280×720 案例 `1176,678` → `1165,671` → `0.910, 0.932`。检测器报的就是手工流程那个左上角，两边对不上说明其中一边测错了。

## 彩色 / 平铺水印另走一条链（全画面）

蓝字、红章、彩色 logo、整页斜向平铺，不局限四角：

- 候选：`S ≥ 45 且 V ≥ 38 且 max|ch − lum| ≥ 12`；总像素需落在 `[max(260, 4e-5·面积), 0.45·面积]`，越界直接放弃（太少是噪点，太多整页都是彩色内容）。
- **主色必须是主峰**：色相直方图（环形拼接 + 宽 19 平滑）峰值占比 `≥ 0.24`，只有 `|hue − peak| ≤ 16` 的才算 mask —— 否则把正文黑字的多支色偏混进来。
- 形态学 `3×3` open + `(0.01·min(W,H) 取奇)` close；连通域面积 `≥ max(14, 1.2e-5·面积)`、单边 `≤ 0.9W/H`；聚类 `gap = max(8, 0.012·min(W,H))`。
- 簇级淘汰：像素 `< 150`、`density ∉ [0.012, 0.62]`（高于 0.62 是实心色块不是半透明水印）、面积 `> 0.55·画面`。按像素数排序取前 10。
- 与角落检测结果重叠过半的簇不重复上报。

## 修补链顺序（逐框依次尝试，命中即止）

`逐像素反解 unblend` → `灰白水印掩膜修补` → `平移取样贴片` → `cv2.inpaint 内容填充`。

**逐像素反解（首选，也是工具化优于手工贴片的地方）**：按 `观测 = 覆盖·水印色 + (1−覆盖)·原色` 反解，不搬运任何邻域内容 —— 手工贴片把邻域结构搬进来，正是「空白处长出字」的成因。写这套判据必须记住：

- **覆盖度只能用零均值色度在水印方向上的投影**。改用「离纸面多远」/纸色锚定投影 → 中性黑正文对这条水印射线的夹角余弦高达 0.86，比真水印还像，整页扫下来字被抬亮一大片。
- **「这一带是白纸」只能靠空间判据**：中性暗像素（`lum < 0.72·纸亮度` 且 `chroma < 34`，必须排除蓝水印本体，它自己就够暗）膨胀 13px 成安全边距，21×21 窗口内一个不剩才算。偏色方向、离纸面多远都分不开「水印压白纸」和「水印压正文」。
- **覆盖带**：`< 0.10` 视为纸面噪声不动，`> 0.34` 视为实心直接反解（smoothstep 过渡）。放开强度是为了不敢碰笔画；但压纯白纸的那部分因此只抬起一半 → 留一层灰影（**这就是「原本空白的地方出现文字」的成因**）。只有上面那条 `on_paper` 空间判据成立才允许补满。
- **覆盖上限 clip（nominal 不透明度 0.90）与分母下限必须配套**：`1 − 覆盖 → 0` 时反解奇异，clip 后必须留 `0.08` 兜底，且 clip 值与 nominal 取值不一致就是残影/halo 的来源。覆盖顶满时唯一稳的答案是纸色本身。
- **不许凭空造内容**：反解结果 `≥` 原亮度（不许造出更黑的笔画），纸面像素 `≤` 纸亮度 + 6（不许抬过白纸）。
- **还原像素的色度回到纸面自身色度，只提亮度不提色偏**（`base = 目标亮度 + (纸色 − 纸均值)`）。否则蓝水印位置会出现暖橙补色斑——水印去掉了，那里变成一块橘色。
- **整页清除要有闸门**：整页拟合出的水印簇数 `≥ 3` 才整页清；只有一处就只修选区，否则单个角落 logo 会误伤整页。
- **只拿到一块选区**（没做整页拟合）时，选区边缘一圈 `≈ (膨胀+窗口)/2` 必须标成「不是白纸」：边界外有没有正文无从得知。
- 灰白水印兜底：`deviation = medianBlur(gray,31) − gray`，取 `> 11` 且四周都是纸面、且不在正文 7×7 邻域内的像素；扩边与羽化一律不许碰「明显比纸面暗且不偏色」的笔画。
- 平移取样：四个方向（左/右/上/下）各算候选源框，跳过越界、尺寸不匹配、以及**与其它水印框相交**的源（否则把另一处水印搬过来），用「目标边界列 vs 源边界列的平均绝对差」选最小者。平坦纸面这条通常水平方向直接胜出，与手工流程「平坦纸面单块横向平移即可」一致。羽化 `feather = clip(min(boxW,boxH)/6, 2, 7)`，只在该边不贴画面外框时羽化。
- 四个方向都不合格才 `cv2.inpaint`，并在结果里报「N 处周边空间不足，已改用内容填充」；选区面积占画面 `> 18%` 时提示「选区较大，建议缩小后复查」。回退必须说出来，不要静默换方法。

## 自动验收闸门（前后同区对比，缺一不可）

```python
def wm_score(im, src):        # 手工贴片：补丁区与参照行的平均绝对差
    ...                       # 判据 >10 未净、<5 干净
def blue_count(rgb):          # 工具化：水印色残留计数（蓝水印示例）
    f = rgb.astype(np.int16); b, r = f[..., 2], f[..., 0]
    return int(np.count_nonzero((b - r > 24) & (b > 90)))
bg = np.percentile(lum_before, 80)                      # 纸面亮度
real_ink = (lum_before < bg * 0.6) & (chroma < 34)      # 真正文（排除蓝水印本体）
erased   = count(real_ink & (lum_after - lum_before > 26))   # 被抹亮的正文
darkened = count(real_ink & (lum_before - lum_after > 26))   # 被抬暗的正文
washed   = count(dilate(erode(glyph),9x9) & (lum_after - lum_before > 26))
```

实跑判据（本批 5 页文档 × 多轮回归，约 800×1000、每页 2–5 框，单页 0.7–1.1s）：

- `page_blue 37461 → 0`，多数页直接归零；残留 `> 1%` 原值就是没清干净。
- `erased` 只允许个位到百级（占 `real_ink` 像素 `< 0.3%`），`darkened` 必须为 0 —— 正文只许变深或持平。
- `washed` 在蓝字压住正文时**必然很大**（本批 4300–6650），它不是失败信号，而是「这些位置必须放大肉眼看」的清单。
- **`wm_score` 单独用不够**：它只回答「水印还在不在」，回答不了「有没有误伤正文」；逐像素反解不搬邻域，参照行差值天生偏低。工具化时两个指标一起看。
- 不合格**不自动重做**（与手工流程同规）：标记出来交人判，把放大对比图一起给出。
- 缩略图、字符图都不能当判据，必须以放大 4–5 倍的目标区域图为准。

## 视频路径

- 首选 `ffmpeg -vf delogo=x:y:w:h:show=0` 一次编码，音频 `-c:a aac` 或 copy，`-progress pipe:1` 拿 `out_time_us / duration` 报进度。
- **硬前提**：每个框必须严格在画面内 —— `x0 ≥ 1 且 y0 ≥ 1 且 x1 ≤ W−1 且 y1 ≤ H−1`。角落水印十有八九触边（本技能案例的水印就贴右下边），此时 **delogo 直接失败**，必须**自动回退逐帧**：`rawvideo rgb24` 解码 → 每帧走上面同一套修补链 → `libx264 -crf 18 -pix_fmt yuv420p` 重编码，音频从原容器 `-map 1:a:0?` 带过来，配 `-shortest -movflags +faststart`。
- 帧率取 probe 的 fps，`≤ 0.1` 时兜底 25；输出奇数尺寸要 `pad=ceil(iw/2)*2:ceil(ih/2)*2`（delogo 路径用 `scale=trunc(iw/2)*2:...`）。
- 回退要写进结果文案：「视频水印靠近画面边缘，已改用逐帧修复（耗时较长）」，让用户知道为什么慢；先写 `.part.mp4` 再原子改名，失败时删半成品。

## 依赖与自检

- 工具化需要 numpy + opencv-python-headless（视频再加 imageio-ffmpeg）；手工贴片仍然纯 PIL 就够，两条路线别混用依赖。
- 回归可以直接驱动函数面而不必点 UI：`detect_watermark(rgb)` → `regions_to_boxes(regions, W, H, padding)` → `remove_boxes_inplace(rgb, boxes, "smart")`，逐夹具打印上面那几个计数器即可（参考实现 `work/qa/_check.py`）。
- 检测框**必须先显示给人核对再跑**（「在右下角找到疑似水印，请核对选框位置」）：自动识别 ≠ 自动放行。
- 前后对比面板要能自由翻页、且不被结果面板遮挡（`z-index` 撞车会让「查看处理结果」看起来点了没反应）—— 否则每轮回归只能靠人肉重跑脚本。
