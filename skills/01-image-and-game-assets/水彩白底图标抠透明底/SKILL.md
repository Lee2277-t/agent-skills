# 水彩图标背景分离

## 先诊断，后定算法

查看原图尺寸、网格、背景纸纹、主体白色区域、阴影与预期输出，使用用户指定的素材目录。不要假定某个 Godot 工程、色调、96/256 尺寸或历史脚本仍然存在。

在当前宿主允许的图像处理方式下选择工具；若原图已有有效 alpha，保留并检查，不重复抠图。保留原图，先用一两个图标验证再批量。

## 背景与透明度

- 颜色距离可辅助识别与画布边缘连通的背景，但不能把主体内部所有亮色都当背景。
- 主体含白色填充时，先确定主体遮罩，再按几何边缘生成 alpha；水彩透明笔触、投影和背景纸纹应分别判断。
- 阈值、连通域面积和羽化宽度要按本图尺寸与样本调整，不把历史数值当通用门槛。
- 计算颜色差平方时使用不会溢出的类型；检查 alpha 是否有效，避免只移动遮罩而没有同步 RGB。

## 拆分与交付

有明确网格且物体不跨格时按网格切；连通域可分离时按真实主体切。粘连或遮挡无法可靠拆分时标注需重绘的部分，不静默等分切坏主体。

导出 RGBA PNG，按任务尺寸等比缩放并保留边距。灰底、深底、浅底及实际游戏背景上都要检查，重点看白边、破洞、裁边和缩略清晰度。动画另验各帧锚点与动作，不用静态图标标准判断位移。
