# 陪伴 AI 记忆与感知

先确定当前要解决的是遗忘、音乐分析还是陪看，检查项目宿主、现有接口和已有能力，只读取对应参考：

- 跨会话记忆、上下文预算和人格连续性：[冷热记忆](references/memory.md)。
- 歌曲节拍、响度和段落变化：[音乐分析](references/soundcheck.md)。
- 从实际音频分析分段情绪、识别乐器候选或增强音乐鉴赏：[情绪与乐器识别](references/music-understanding.md)。
- 屏幕变化检测、触发模型看图及节流：[屏幕陪看](references/whale-sense.md)。
- 上游来源、相关技能及收录状态：[来源与相关技能](references/sources.md)。

这些资料基于公开文档和关键源码学习，不代表宿主插件已安装。给出当前功能到真实工具/接口的映射；没有工具时做设计或适配代码，不能凭技能名称宣称获得听觉、视觉或永久记忆。

## 接入与验证

1. 阅读项目规则及对应源码，找输入、存储、模型请求构造、输出和退出清理位置。DSH 的工具注册和 `agent.followup()` 要换成目标宿主实际支持的接口，不能原样假设 Codex/Electron 具有这些方法。
2. 选择能验证一个行为的最小切片：记忆从写入到重启召回；音乐从文件到带来源测量；陪看从合成图差异到节流决策。先测纯处理逻辑，再在已授权宿主中测联动。
3. 记忆必须检查最终发送的模型请求，而非只看数据库或界面；感知必须检查模型实际收到了什么证据，工具返回图片路径不等于模型已经看图。
4. 区分测量、推断和未知。保存必要时间戳、来源路径及数据版本。对无法识别的音色、无字幕语音、缺失记忆返回不确定，不补写合理故事。
5. 验证受影响链路及失败/取消/清理行为；报告实际命令、结果和缺口。没有端到端环境时写明仅静态核对或局部测试，不承诺“不失忆”或固定 token 节省率。

本技能用于后续明确请求的设计与接入。读取它不会自动开启持续屏幕采集、改写角色设定或重启正在使用的桌宠。
