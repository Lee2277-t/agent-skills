# 制作记录、提示词与验收约定

这是为了让教程流程可执行而补充的工程约定，不是原作者公开的完整工程或逐字提示词。按项目规模选用，不要求小片段也建立一堆文档。

## 最小制作记录

可在一个项目记录文件中维护以下信息，已有等价文件时复用：

| 记录 | 必需信息 |
|---|---|
| 创意/约束 | 主题、情绪、叙事转折、用途与画幅、角色锁定项、禁改项、已有授权/成本上限 |
| 音乐母版 | 音频路径与版本/哈希、实际时长、录音唱词、音乐结构、节拍/词时序来源和校对状态 |
| 分镜 | 镜号、时间范围、对应歌词/段落、镜头职责、画面、动作、运动、字幕与前后承接 |
| 资产 | 镜号、文件路径、角色/风格参考、是否分层/透明、生成来源、选用状态 |
| 返修 | 问题时间码、观察证据、根因、改动与验证、仍待人工确认的部分 |

逐字数据最少包含 `text/start_seconds/end_seconds`，段落与镜头可以有独立的音乐职责。估算数据另标状态，不混入已实测对时。优先复用 LRC/SRT/现有工程格式，不为本技能强制转换成专用 schema。

## 可直接改写的工作提示

### 创意澄清

“根据我已有的信息，先复述这支 MV 的核心冲突和情绪落点。只问会明显改变方向的缺失问题，给一个推荐方向；不要先扩成整部世界观。确认后写出开头、转折、高潮和收束。”

### 歌词与风格

“围绕已确认的主题写可唱歌词和歌曲结构，口吻与人物一致。歌词和编曲/人声要求分别标清，按当前音乐工具的输入方式整理。给出有区别的风格候选及试听比较标准，不保证未试听歌曲的质量。”

### 音乐到分镜

“使用这份实际音频与唱词时序规划镜头。解释每段音乐的情绪变化，逐句安排视觉职责，再按乐句合并/拆分。给出镜号、时间、构图、动作、镜头运动、字幕位置与承接。标明估算项，不为了凑镜数平均切段。先交可审阅分镜，不批量生成素材。”

### 一致性生图

“沿用已确认角色参考与风格基准。当前镜号的主体、动作、情绪、环境和构图如下。只改本镜需要的姿态与景别，保持脸、发型、服装和比例。为动画裁切及字幕预留空间；需要透明/分层时分别输出，不在图片里画歌词。”

### 动画与审片

“以定稿歌曲为主时间轴，用当前工程实现本镜。帧号决定状态、随机效果可重现。先渲代表性短段，用实际素材检查字幕、角色、转场与音乐层次。对问题给时间码、具体原因和修复；只重渲受影响范围，再核对最终编码文件。”

## 代码动画路线的实用边界

- Remotion/Canvas/WebGL 可以使静态素材运动、制造空间层次和排版节奏，但不会自动补齐角色看不到的身体结构。缺侧面/背面时选择可实现的运动或生成相应素材。
- 检查透明 PNG 的 alpha 与边缘；把角色与背景分层后做位移，先看是否露出空洞。重叠姿态直接溶解可能出现双脸/重影，按镜头意图选切换、遮挡或补帧。
- 节拍网格、词对时、镜头切点是三种数据，不可互相替代。一个词可以跨多个动画阶段，一镜也可以覆盖多句；以听觉和阅读节奏判断。
- 若帧率为 F，共享边界按同一规则换算，例如 `frame = round(seconds * F)`；镜头采用 `[startFrame, endFrame)`，时长为二者差。保留整数帧边界作为渲染依据，防止各处独立取整造成缝隙。
- 音频母版有变，先失效相关时序记录，再更新字幕、镜头和缓存；仅修一个角色姿态，不重新分析整首歌或重写全部分镜。
- 只有实际运行时才依据项目版本核对 Remotion 等工具的当前官方文档、依赖和命令。不要照搬其他仓库的 Linux 路径、私有 MCP、账号配置或云端渲染服务。

## 分阶段验收

| 阶段 | 看什么 | 失败后回到哪里 |
|---|---|---|
| 选歌 | 实际试听、唱词、结构与主题；只有分析结果不能替代试听 | 歌词/音乐候选，保留已选与淘汰理由 |
| 时序 | 词句抽查、人声边界、头中尾节拍漂移 | 对齐数据，不先修改画面遮掩偏差 |
| 分镜 | 故事能否看懂、镜头职责、高潮与承接、可制作性 | 计划；批量美术前尽早改 |
| 美术 | 角色/服装一致、清晰度、分层、透明、镜头构图 | 有问题的素材，不盲目整批重做 |
| 动态预览 | 字幕可读、变形/穿帮、运动和音乐匹配、转场接缝 | 对应镜头或共享动画逻辑 |
| 最终编码 | 文件可解码、正确音轨、尺寸帧率时长、关键时间点与完整播放 | 导出配置或受影响镜头；之后再核对最终文件 |

“每秒一张联系表”只能检查覆盖到的静帧，无法排除中间一帧闪烁；过渡疑点应导出连续帧或短视频复核。审美评分应附具体观察，不能靠自评不断上涨宣称合格。原教程提及的个案分数不是经过校准的评分系统。

## 能力不足时的交付

没有音频分析：交付估算分镜与需要实测的节点。没有生图：交付参考约束和逐镜提示词。没有音乐/视频服务：交付工具适配输入与操作说明。没有渲染器：交付工程或制作方案及依赖缺口。未完成的阶段明确标记，不用占位文件冒充最终素材。
