# AI 音乐 MV 全流程

把人负责的创意与审美决定，转成 AI 能执行、能返修的制作任务。默认主路线是“歌曲 → 分镜 → 一致性图片/分层素材 → 代码动画与字幕 → 成片”；只有镜头确实需要时才使用图生视频，不把昂贵视频生成作为所有镜头的前提。

本技能由指定 B 站教程的可核实资料与画面蒸馏，并补充工程做法。来源、章节及证据局限见 [教程依据](references/tutorial-source.md)；GitHub 上相关技能及适配边界见 [开源方案对照](references/github-options.md)。不能把补充建议说成作者原话。

## 1. 接手与创意

先盘点已有歌曲、实际唱词、角色参考、素材和工程，判断从哪一阶段续作，避免重做已确认的部分。只询问当前阶段缺少且会改变制作方向的信息：主题与情绪、用途/画幅、歌曲是否定稿、风格与不可改元素。一次集中问关键问题，不机械套五轮问卷。

- 只有点子：用少量具体问题梳理“谁想要什么、发生什么变化、观众最后记住什么”，给推荐方向和可选差异，形成简短创意稿。
- 没有歌曲：写实际可唱的歌词、结构及适配所选音乐工具的风格提示词；区分演唱文字与制作备注。可为 Suno/Mureka 等提供提交稿，但不虚构已生成歌曲或现有账号能力。
- 选歌时对候选用中性编号，按旋律记忆点、人声、歌词可懂度、段落变化和主题贴合比较；能够实际听取才评价声音，否则列为待试听。用户选定的音频成为主版本。
- 已有歌：跳过写歌和选歌，不默认更换音频。只有分析样例或试听片段时不能声称整首已定稿。

教程中的人工节点是概念、选歌、分镜与最终审美反馈；有用户明确授权或已确认的节点可直接继续，不在每个小步骤重复索要许可。没有关键审美决定时先完成可审阅方案，不擅自全量出图、购买服务或发布作品。

## 2. 让制作服从音乐

把定稿歌曲作为唯一母时间轴，记录文件、时长、画幅、帧率及版本标识。分析结构、节拍/强拍、能量起伏和人声起止，并把实际唱词对齐到录音。

- 时间来自实际音频、可信 LRC/逐字数据或测量，不能从歌词字数推算出“精确”时间。缺分析工具时先做估算分镜并标注待实测，不编造 BPM、音频分析或字幕对齐结果。
- 歌词以实际演唱为准；自动识别需校对中文同音字、重复句、语气词、合唱及漏字。逐字效果必须有逐字依据；仅有逐句 LRC 时先做逐句字幕。
- 核对节拍网格的起点、半速/倍速及整曲漂移，不用固定 BPM 无限外推代替真实节拍。慢段允许留白，强段按音乐变化增强，不要求每拍切镜。
- 歌曲换版本/删段后，重新核对歌词、节拍与镜头范围；不偷偷挪动歌曲去适配已做画面。

具体记录与提示词模板按需读 [制作与验收约定](references/production-contracts.md)。

## 3. 分镜先于批量出图

先把歌词含义和音乐情绪变成视觉叙事。每句歌词先安排画面职责，再按乐句、段落和可读时长合并/拆分；不是机械“一句一切”，也不是平均切成固定数量。

分镜至少给出：镜号、时间范围、歌词/音乐依据、画面职责、构图/景别、角色动作、镜头运动、字幕安排、承接方式与素材需求。区分测量时间与估算时间，说明开头吸引点、高潮、重复副歌如何升级以及结尾如何收束。

先给用户可审阅的分镜表/低成本动态预览，按已确定的授权完成确认后再大批生成素材。分镜变化优先改计划，不用已生成素材反向绑架歌曲或剧情。

## 4. 美术与镜头素材

先建立角色与风格基准：脸型、发型、服装、比例、标志物、配色、线条/光照、背景及画幅。复用用户已确认参考，局部姿态变化不重新设计角色。

- 先做代表性镜头，确认角色和风格，再按镜号扩展。每张图的提示词引用同一基准，另写本镜动作、构图、情绪与需留出的字幕空间。
- 按合成需要分离角色/背景/前景/道具；需要透明素材时明确透明输出，不把白底或棋盘格当真透明。避免让生图模型画必须清晰可读的歌词，文字由排版层生成。
- 预留运动边缘、裁切空间和角色活动范围；检视脸、手、道具、服装连续性与分层接缝，记录镜号到实际文件的对应关系。
- 静态图可支持景深、推拉、位移、分层遮挡和动作替换，不能据此宣称自然三维转身或精确口型。需要连续复杂动作再选视频生成/专用动画路线，先验证一镜的可用性。
- 使用当前可用工具并遵守其实际接口；工具不可用时交付可直接提交的提示词/素材清单及未完成项，不虚构下载链接、生成成功或付费调用。

## 5. 代码合成与节奏设计

默认采用项目现有技术栈；新工程优先评估教程的 Remotion 路线，适合 Canvas/WebGL/p5.js 的镜头可局部使用，不为炫技堆多个引擎。先核对实际依赖与可用渲染器，不写不存在的运行命令。

- 画面由帧号/时间和固定输入决定；随机效果固定种子，避免按系统时钟、累计状态或未固定随机数渲染，确保能单独重现任意问题帧。
- 音乐始终为主音轨，字幕按对时数据进出。代码动画、相机、字号和特效随音乐层次变化，每项效果需说明对本段情绪/叙事的作用。
- 先做一段包含字幕、角色、转场的代表性短预览，再扩展全片；标题卡、遮罩、粒子和字体都使用最终素材检查。人脸保持正常比例，不能靠非等比拉伸填满画面。
- 特效不能盖住角色表情或歌词；在目标尺寸核对可读性、安全区、对比度与视觉焦点。静段允许安静，副歌重复要在构图或动作上递进。
- 秒转帧统一换算共享边界，镜头使用明确的起止规则，检查漏帧/重复帧。调整剪辑时同步检查后续字幕、音乐节点和镜头转场。

## 6. 审片、返修与交付

先审代表性帧和每个镜头/章节，重点审接缝、字幕进出、高潮、首尾和异常动作；静帧合格后仍需检查动态节奏。抽帧审查叫抽帧，实际连续逐帧审查才能称逐帧；机器评分只是定位问题的辅助。

用“时间码/帧号 → 具体问题 → 原因 → 修复 → 复验”记录。技术项检查角色变形、资源缺失、黑帧、裁切、字幕覆盖、时序和音轨；审美项描述叙事、层次、重复和情绪，不只给一个分数。教程个案的分数和工期都不是通用交付门槛。

- 局部修改先重渲相关镜头和相邻接缝；共享动画/时间轴/音轨改变才扩大范围，不因用户一句反馈重生成全片素材。
- 不盲目自评循环。可定位的缺陷先修；连续返修没有改善或审美方向不明时，给具体对比和推荐方案让用户判断。
- 最终从编码后的成片核对分辨率、帧率、时长、音视频轨、字幕以及曾出问题的时间点；预览或中间帧通过不代替最终文件通过。实际不能听或播放的部分明确待验。
- 交付视频、必要工程/素材映射和精简说明，列出所用工具与人/AI 的实际分工。没有实际渲染就交付制作包并写明未出成片；发布只在用户授权的目标与可见性下执行。

不要把本次“读取教程并创建技能”误当作已获授权制作付费歌曲、批量生成素材、安装大型模型或上传作品。首次使用该技能时按当前任务和授权执行，既有授权持续有效。
