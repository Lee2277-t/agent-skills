# 审美方向：先有判断，再谈技巧

## 1. 审美是可训练的判断

Emil Kowalski 的定义：taste 不是个人偏好，而是 trained instinct——能越过表面，认出什么东西把它抬高了。训练只有三件事：

1. **大量看好的**：把时间花在最好的作品上，而不是信息流里随机刷到的。
2. **说清为什么好**：不要只标记「好看/不好看」，要拆出具体手段。直觉负责发现，语言负责校准。
3. **动手并接受批评**：判断力和手艺是两条腿，只看看不动手，永远停在「眼高手低」。

**Taste gap**：你能看出自己的作品不够好，说明判断力已经超过了手艺。这不是失败，是正常阶段。继续做，差距会缩小。

## 2. 建参考库，不建收藏夹

收藏夹的问题是：存了几百个链接，要用时一个都想不起来。参考库的做法是：

- 看到好页面，截 **一张全图 + 一张关键局部**，存进项目的 `refs/`（放进 `.gitignore`）。
- 文件名带维度前缀：`refs/type__linear-pricing.png`、`refs/color__stripe-docs.png`、`refs/layout__every-layout-sidebar.png`。
- 每张图配一行字：**取什么**（例：用 1px 边框代替阴影）、**不取什么**（例：它的品牌色和插画）。
- 按**维度**分组，不按网站分组。改排版时只翻 `type` 组，避免一次学五件事。

判断一个参考值不值得存：能不能用一句话说出它做对了什么。说不出，它只是好看，不是参考。

## 3. 拆解四问

看任何好设计，按顺序问：

1. **第一眼看到什么？** 它想让你先看什么。
2. **用什么手段做到的？** 大小、字重、颜色、留白、位置——通常只有一个主导，不是五个一起上。
3. **它删掉了什么？** 没有边框？没有图标？没有第二个强调色？
4. **换成我的内容还成立吗？** 不成立的是皮肤，成立的是方法。

第四问是「学」和「抄」的分界线。方法可以搬，皮肤搬过来就是撞脸。

## 4. 先写设计简报，再写代码

Anthropic 的 `frontend-design` 技能要求两遍走：先出方案，再对照简报自我审查，最后才写代码。最小简报只要五项：

- **主体**：这是什么页面，给谁用。
- **唯一任务**：这个页面只促成哪一件事。
- **气质**：三个形容词，并写出**反例**（例：要「冷静、精确、略机械」，不要「温暖、圆润、插画感」）。
- **一个记忆点**：整页只允许一个地方大胆，其余保持安静。
- **约束**：必须保留的品牌色、字体、组件。

没有简报就直接选「现代、简洁、渐变」——那是在选默认值，不是在选方向。

## 5. 大胆只花在一个地方

「Spend your boldness in one place.」一个页面里，大胆只能出现在一个元素上：一张大图、一个超大标题、一个反常规的网格、一个动效。其余全部退到背景。

配套的是 Chanel 规则：出门前照镜子，摘掉一件配饰。改完问自己「我删掉了什么」，答不上来就是加多了。

## 6. 结构装置必须承载信息

Anthropic 列出的典型模板装饰，只有在内容真的是那个结构时才用：

| 装置 | 什么时候才成立 |
| --- | --- |
| `01 / 02 / 03` 编号 | 内容真是步骤、时间线或排序 |
| 全大写小标签（eyebrow） | 需要给一组内容分类，且分类本身有用 |
| `A · B · C` 元信息串 | 三项确实是同类元数据（作者、日期、阅读时长） |
| `标签 — 短语` 破折号 | 短语确实在解释标签 |
| 每个标题前挂图标 | 列表需要快速扫读；普通标题不需要 |
| 按钮/链接尾部 `→` | 确实表示跳转或前进 |

判断法：**删掉它，信息有没有丢失？** 没有，就是装饰；装饰只在「一个大胆点」里出现一次。

## 7. 当前 AI 的默认长相

Anthropic 的 `frontend-design` 技能列出的五类高频默认：

1. 暖米色背景（近 `#F4F1EA`）+ 高对比衬线大标题 + 陶土色强调（近 `#D97757`）。
2. 近黑背景 + 一个荧光绿或朱红强调色。
3. 报纸式版面：发丝线、零圆角、密集分栏。
4. SaaS 卡片套装：所有内容切成同尺寸圆角卡片、同一个圆角、同一层灰色阴影、渐变当装饰。
5. 模板化外壳：每个标题上全大写 eyebrow、`·` 连接的元信息、`—` 标签、近黑 `#0B0B0B` 代替黑、等宽字体标小字、链接尾部 `→`。

这些不是禁用名单，是**默认值提醒**：如果简报没有指定，就别把宝贵的自由花在这些默认上。品牌简报明确要求时，照做，简报永远优先。

与 `ai-tells.md` 的关系：那份是逐条症状表，这份是方向层。改完两份都要过。

## 8. 审稿：隔十分钟再看

1. **这是哪个产品？** 答不上来，说明没有识别度。
2. **最先看到什么？** 和最该做的事不一致，说明层级错了。
3. **哪里「见过很多次」？** 那里就是默认值。
4. **再删一件配饰还成立吗？** 成立就删。

## 9. 四周训练路径

每周只练一个维度，不要同时改五项。

| 周 | 维度 | 看什么 | 做什么 |
| --- | --- | --- | --- |
| 1 | 字体 | Modern Font Stacks、Typewolf、Bringhurst 的字阶 | 给同一个页面换三套字体组合，只改字体 |
| 2 | 颜色 | Refactoring UI 色板章节、OKLCH 调色器 | 用 9 档法重做一套色板，替换现有页面 |
| 3 | 布局与间距 | Every Layout 的 Stack、Cluster、Switcher | 只用 8pt 档位重排一个页面，不加任何装饰 |
| 4 | 动效与细节 | Emil 的七条动效建议、Vaul 和 Sonner 的源码 | 只做按压反馈、进场、origin 三件事 |

每周结束写五行：改了什么、为什么、前后截图、还差什么。四周后回看，判断力通常比手艺先涨，这是正常的。

## 10. 什么时候停止

改到「四问都能答好、AI 味清单全过」就停。继续抠细节的收益很低，而且容易过度设计。真正的提升来自内容——真实截图、具体文案、真的能用。
