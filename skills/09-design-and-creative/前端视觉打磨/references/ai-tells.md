# AI 味清单

这是这个技能的核心。逐条对照，命中就打掉。

判断标准不是「这个元素丑不丑」，而是「**它是默认值，还是有人做过选择**」。AI 生成的前端，特征是每个属性都取了「最安全的中庸值」：圆角 16px、阴影三层、间距 24px、字号 16px、渐变紫蓝。安全 = 没有选择 = 一眼 AI。

---

## 一、视觉层面

### 1. 渐变滥用

| 症状 | 为什么是 AI 味 | 怎么改 |
| --- | --- | --- |
| 紫蓝渐变主色（`#667eea → #764ba2` 那一挂） | 这是 tailwind / shadcn 示例里的默认色，几万个 AI 生成项目都用它 | 换成一个**实色**主色。真要渐变，只在 1 个地方用（如 hero 背景），且用同色系深浅 |
| 渐变文字标题（`background-clip: text`） | 2023 年后成了 AI 生成的标志 | 删掉。用字重和字号做层级，不靠颜色 |
| 每个按钮都带渐变 | 按钮的功能是「可点」，不是「装饰」 | 主操作实色，次操作描边，第三级纯文字 |
| 卡片背景渐变 | 卡片是容器，容器不该抢戏 | 纯白/纯浅灰 + 1px 边框，够了 |

例外：品牌本身是渐变（如某些游戏/音乐产品）可以留。

### 2. 圆角与阴影

| 症状 | 怎么改 |
| --- | --- |
| 圆角值五花八门：4/8/12/16/20/24px 全都有 | **只留 2 档**：小元素 6px，容器 12px。或者干脆全部 8px |
| 按钮全圆角（`border-radius: 9999px`） | 除非是 tag/chip，按钮用和卡片同一档圆角 |
| 阴影三层叠加（`0 1px 2px, 0 4px 8px, 0 12px 24px`） | **只留一层**，且透明度 ≤ 0.08。阴影是「浮起来一点」，不是「发光」 |
| 卡片 hover 时放大 + 阴影加深 + 边框变色，三件事同时发生 | 只动一件，通常只加深阴影或只改边框 |
| 玻璃拟态（`backdrop-filter: blur(20px)` + 半透明白） | 全站最多 1 处（比如吸顶导航）。到处都是就是模板货 |

### 3. 图标

| 症状 | 怎么改 |
| --- | --- |
| 用 emoji 当图标（🚀 ✨ 🎯 💡 🔥） | 换成 SVG（lucide / heroicons 单文件内联），或干脆去掉图标用文字 |
| 每个标题前都挂一个图标 | 标题本身有层级就不需要图标；图标只用在「需要快速扫读的列表项」 |
| 图标尺寸和文字不对齐 | 图标 `width/height` 设成 `1em`，`vertical-align: -0.125em` |
| 图标风格混用（线性 + 面性 + 彩色插画） | 全站只用一种，线性最安全 |

### 4. 颜色

| 症状 | 怎么改 |
| --- | --- |
| 颜色超过 6 个（不含灰阶） | 收到 3 个：主色、一个强调色（成功/警告）、一个危险色 |
| 纯黑 `#000` 正文 | 用 `#1a1a1a` 或 `#111`，纯黑在屏幕上刺眼 |
| 纯白 `#fff` 大面积背景 + 纯黑文字 | 背景用 `#fafafa` 或 `#f8f9fa`，对比更柔 |
| 灰色用了 5 种（`#333 #444 #666 #888 #999`） | 灰阶只留 4 档：正文 `#1f2328`、次要 `#59636e`、占位 `#8b949e`、边框 `#d1d9e0` |
| 饱和度过高的主色（如 `#FF0000`、`#00FF00`） | 降饱和到 60–75%，亮度调到 45–55% |
| 深色模式下直接反色 | 深色模式不是反色：背景用 `#0d1117` 而不是 `#000`，卡片用 `#161b22`，文字用 `#e6edf3` 而不是 `#fff` |

### 5. 留白与对齐

| 症状 | 怎么改 |
| --- | --- |
| 间距全是 `24px` | 用 4 或 8 的倍数做**有意图的档位**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。相邻元素 8，分组之间 24，区块之间 64 |
| 内容贴边（没有 `max-width`） | 正文容器 `max-width: 65ch`（约 720px），页面容器 1100–1200px |
| 左右边距在窄屏塌成 0 | 容器 `padding-inline: max(16px, 4vw)` |
| 卡片内容垂直居中导致高度不齐 | 卡片用 `flex-direction: column`，把操作区 `margin-top: auto` 顶到底部 |
| 所有东西都居中 | 长文本左对齐。居中是给短标题和按钮的 |

## 二、文案层面（最容易被忽略，也最露馅）

### 禁用词表

命中就换：

```
赋能  一站式  无缝  极致  打造  助力  引领  重新定义  颠覆
全方位  深度赋能  闭环  抓手  生态  矩阵  底层逻辑
强大的  革命性的  智能的  全新的  前所未有的
Lorem ipsum  TODO  TBD  待补充  示例文本
```

### 换成什么

| AI 味写法 | 人话写法 |
| --- | --- |
| 「一站式解决你的所有需求」 | 「下载后双击就能用」 |
| 「强大的 AI 能力，赋能你的工作流」 | 「把录音自动转成文字，一分钟出结果」 |
| 「极致简约的设计语言」 | 「只有三个按钮」 |
| 「无缝集成你的现有系统」 | 「支持导入 CSV」 |
| 「立即开始你的旅程」 | 「下载」 |
| 「我们致力于…」 | 删掉，直接说做什么 |

### 三条文案规矩

1. **主标题说结果，不说能力**。「转写 1 小时录音只要 2 分钟」> 「强大的语音识别」。
2. **按钮说动作**。「下载 Windows 版」> 「立即体验」。
3. **每句话至少有一个具体名词或数字**。没有具体信息的句子，删掉。

## 三、结构层面

| 症状 | 怎么改 |
| --- | --- |
| 首屏是「大标题 + 副标题 + 两个按钮 + 三列 feature 卡片」 | 这个版式本身没错，但**必须有真实截图**。没截图的 hero 就是模板 |
| 三个 feature 卡片，每个都有图标+标题+两行描述 | 卡片数改成 2 或 4（3 是最模板的数字），或者用列表替代 |
| 底部「Powered by XXX」 | 删掉，除非真有合作 |
| 每个区块之间都有波浪/斜切分隔 | 最多 1 处，或者全部用留白分隔 |
| 页脚有 4 列链接但只有 2 个页面 | 页脚只放真实存在的链接 |
| 空状态是「暂无数据」 | 写「还没有添加项目。点右上角 + 新建一个」 |
| 加载状态是转圈 | 用骨架屏（skeleton），尺寸和真实内容一致 |

## 四、动效层面

| 症状 | 怎么改 |
| --- | --- |
| 每个元素进页面都 fade-in + 上移 | 只在**首屏**做一次，且时长 ≤ 400ms |
| `transition: all 0.3s ease` | 指定属性：`transition: background-color 150ms ease, box-shadow 150ms ease` |
| hover 时 `transform: scale(1.05)` | 缩放到 1.02 就够了；或者用位移 `translateY(-1px)` |
| 用了 `ease-in-out` 但感觉「黏」 | 交互反馈用 `ease-out`（快进慢出），进出场用 `cubic-bezier(0.16, 1, 0.3, 1)` |
| 滚动视差 | 除非是展示型网站，别用 |
| 动画时长 500ms 以上 | 交互反馈 100–200ms，进出场 200–400ms |

## 五、技术层面（`audit_ui.py` 会查）

- `!important` 超过 3 处 → 选择器层级失控
- 内联 `style=` 超过 10 处 → 样式散落，没法统一改
- 硬编码色值超过 12 个不同值 → 没有 token 化
- 字号超过 5 种 → 字阶没收敛
- 圆角超过 3 种 → 同上
- 没有 `<h1>` 或 `<h1>` 多于 1 个
- `<img>` 缺 `alt`
- 按钮/链接可点区域 < 44×44px（移动端）
- 正文对比度 < 4.5:1

## 六、最后一道：30 秒自检

改完，把截图发给别人（或自己隔 10 分钟看），问三个问题：

1. **这是哪个产品？** 如果答不上来，说明没有识别度（可能太通用）。
2. **最先看到的是什么？** 如果和最该做的事不一致，层级错了。
3. **哪里让你觉得「见过很多次」？** 那就是 AI 味所在。

三个问题都能答好，才算改完。
