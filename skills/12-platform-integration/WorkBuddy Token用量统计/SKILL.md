# WorkBuddy 日志用量统计

## 执行

脚本默认读取当前用户的 ~/.workbuddy/projects；不绑定用户名或某个内置 Python 版本。用可用的 Python 3 运行本目录脚本：

```powershell
python "<本技能目录>/scripts/token_stats.py" --projects "<日志根目录>" --output "<报告绝对路径>"
```

不指定参数时使用默认日志目录、在当前工作目录输出 Token用量统计.txt。缺失日志根目录或没有日志时返回非零；不要把“没有读取到数据”当成零用量。

## 统计口径

- 按会话目录分组；同一会话中有稳定 message.id 或记录 id 的 usage 按文件名和行顺序保留最后读取的一份，不推断事件时间先后；缺少 ID 的记录逐条计入并标注数量。
- input、output、cache_read 与 total 均按日志原字段展示；total 缺失不强行用输入输出相加补齐，报告说明缺失数量。
- 不假定 input 是否已经包含缓存，不用 input-cache 推导“新鲜输入”，也不假定固定缓存占比。
- 日志字段可能随版本变化，这份记录汇总不等于供应商账单、真实收费或剩余额度。字段含义须结合产生日志的版本确认。
- 只输出用量和必要会话信息，不把完整聊天内容复制进报告。

## 验收

先用合成日志检查重复 ID、缺字段与空目录，再按任务读取真实日志。交付时写明日志根目录、覆盖的会话和缺失字段；未知口径明确标为未知。
